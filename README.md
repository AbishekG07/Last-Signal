\# Last Signal



A sci-fi action-adventure game set in the abandoned Astra-09 research facility. Play as engineer Ethan Cole to restore power, fight malfunctioning robots, and stop the unstable energy core.



\## Technologies Used

\* Unity 6 (URP)

\* New Input System

\* Cinemachine

\* AI Navigation

\* C#



\## Controls

\* \*\*WASD\*\* - Move

\* \*\*Mouse\*\* - Look

\* \*\*Space\*\* - Jump

\* \*\*Left Shift\*\* - Sprint

\* \*\*Left Mouse\*\* - Shoot (WIP)

\* \*\*E\*\* - Interact (WIP)
